# Phase 2: Backend auth and user management

Scope: `backend/backend/api/auth_views.py`, `auth_utils.py`, `views.py`, `serializers.py`, `models.py`, `urls.py`, `utils/responses.py`.

| Location | Severity | Problem | Fix |
|---|---|---|---|
| `api/auth_utils.py:41-51` + `auth_views.py:336-346` | critical | 2FA bypass. A token with `is_tfa_verified: False` (password only) is let through for any path starting with `/api/auth/twofa/`. That includes `twofa/disable/`, which needs no code. Attacker with the password calls disable, logs in again, and 2FA is gone. | Allow only `twofa/verify/` for unverified tokens. Make `disable_twofa` require a valid TOTP code. |
| `api/auth_utils.py:41-46` | high | Same allowlist includes `/api/auth/setup/`. An unverified token can change username/avatar. | Remove `setup/` from the allowlist. |
| `api/auth_views.py:36-81`, `310-333` | high | No rate limit on `login/` or `twofa/verify/`. TOTP is 6 digits; unlimited guesses make brute force practical. | Add DRF throttling (`ScopedRateThrottle`) or a per-user counter in Redis; lock after N failures. |
| `api/auth_views.py:218-227` | high | Intra login falls back to a username lookup. If no profile has this `intra_id` but a user with the same username exists with `auth_method == INTRA`, the caller is logged into that account. Usernames are editable (`setup/`, `settings/update/`), so an intra user can rename to someone's 42 login before that person's first login (account pre-hijack). Legacy intra users with `intra_id = NULL` also match. | Look up intra users only by `intra_id`. On username clash, create with a suffix. Backfill `intra_id` for old rows. |
| `api/serializers.py:80-98` + `auth_views.py:89-125` | high | `username` is a plain `CharField`, so Django's username validator is dropped. Any string is accepted (HTML, spaces, 150+ chars fails only at DB). Combined with frontend `innerHTML` this is stored XSS (Phase 6). Password validators in `settings.py` are never called. | Use `UnicodeUsernameValidator` + `max_length=150` on the serializer field (also in `SetupProfileSerializer`, `UpdateSettingsSerializer`). Call `validate_password()` in register and settings update. |
| `api/views.py:45-87` | high | `settings/update/` changes password and email without the current password. A stolen cookie or one XSS gives permanent account takeover. Password is not validated either. | Require `current_password` for password/email change. Run `validate_password`. |
| `api/auth_views.py:78-80` (and 251, 330) | med | Auth cookie set without `secure=True` and without `samesite`. Firefox does not default to Lax, so with open CORS (Phase 1) cross-site credentialed requests work. | `set_cookie(..., httponly=True, secure=True, samesite="Lax")`. Put it in one helper. |
| `api/auth_views.py:154-200` | med | OAuth flow has no `state` parameter. Login CSRF: attacker can log a victim into the attacker's account. | Generate `state`, store in a short-lived signed cookie, compare in callback. |
| `api/auth_views.py:173,198` | med | `requests.post/get` without `timeout`. A slow intra API blocks the worker forever. `json_response["access_token"]` raises `KeyError` (500) instead of the intended check. | `timeout=10`, use `.get("access_token")`, catch `requests.RequestException`. |
| `api/auth_views.py:250` | med | Callback redirects to hardcoded `https://localhost:1337/`. Breaks any other host. | Read frontend URL from env. |
| `api/views.py:183-202` | med | `get_users` returns every user with `email` (via `UserSerializer`) and allows search by email. Any logged-in user can dump all emails. Block check runs one query per user (N+1) and rebuilds the queryset each loop. | Public serializer without email. Exclude blocked users with one subquery. Paginate. Search by username only. |
| `api/auth_views.py:113-121` | med | User and Profile created without a transaction. If `Profile.objects.create` fails, a user without profile remains and every `user.profile` access then raises. Exists-then-create is racy (unique username -> IntegrityError 500; email is not unique at DB level -> duplicates). | Wrap in `transaction.atomic()`. Catch `IntegrityError`. Add a unique constraint on email (or a profile-level one). |
| `api/auth_utils.py:57-62` | med | Catch-all `except Exception` returns `str(e)` to the client with 500. Wraps the whole view, so any view bug leaks internals and loses the traceback in logs. | Remove the catch-all; let Django log it. Or `logger.exception` + generic message. |
| `api/serializers.py:155-170` | med | `Notification.sender` is nullable, but `get_sender` reads `obj.sender.profile`. A system notification with no sender crashes `me/` (500). | Return `None` when `obj.sender` is `None`. |
| `api/auth_views.py:73-76` | low | Token `exp` built with naive `datetime.now()`. PyJWT treats it as UTC. Lifetime is wrong on a non-UTC host. | `datetime.now(timezone.utc)`. |
| `api/auth_views.py:132-137` | low | Logout only deletes the cookie. Token stays valid 1 day. Password change or 2FA disable does not revoke old tokens. | Add a `token_version` on Profile, put it in the JWT, bump on logout/password change. |
| `api/auth_views.py:301,321` | low | TOTP codes can be reused inside the window. | Store last used time step; reject reuse. |
| `api/auth_views.py:257-286` | low | `enable_twofa` overwrites the pending secret on each call. Fine, but secret stored in plain text in DB. | Acceptable for scope; optional: encrypt with a key from env. |
| `api/serializers.py:63-77` | low | `validate()` is defined inside `class Meta`, so it never runs. The view repeats part of it. | Move `validate` to the serializer class. |
| `api/auth_views.py:30-33` | low | `RegisterUserViewSet` (unauthenticated ModelViewSet on all users) is dead code. Dangerous if someone routes it. | Delete. |
| `api/views.py:90-149` | low | `get_profile` wraps everything in `except Exception` and returns 404, hiding real bugs. History loop does 2 queries per game (no `select_related`). | Remove broad except. `select_related("player1__profile", "player2__profile")`. |
| `api/views.py:69`, `models.py:190-195` | low | Avatar upload: no size limit beyond defaults, saved under `MEDIA_ROOT` unset (cwd) which equals the static dir. | Set `MEDIA_ROOT`, `DATA_UPLOAD_MAX_MEMORY_SIZE`, check file size in serializer. |
| `utils/responses.py:36` | low | `SuccessResponse(data={})` mutable default. Not mutated today. | `data=None`. |
| `api/serializers.py:127-131` | low | Avatar URL decided by substring `"cdn.intra.42.fr" in avatar`. | Store intra avatar in a separate URL field, or check `startswith("https://")`. |
